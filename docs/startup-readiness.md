# 冷启动预热与接流量

应用默认在开放业务流量前执行有限预热。生产和开发模式均启用，普通内存测试通过测试配置关闭；专门的冷启动集成测试显式启用。

## 启动顺序

1. 启动新实例，完成数据库连接、结构校验和既有启动任务。端口开始监听不代表实例已经就绪。
2. 就绪探针 `/actuator/health/readiness` 返回非成功状态，业务请求返回 `503`，带 `Retry-After: 2` 和 `Cache-Control: no-store`。健康检查仍可访问，原有认证规则继续生效。
3. 应用先用仅在进程内使用的测试令牌预热签名校验，不创建账号或会话；随后通过本机回环地址调用匿名首页、未缓存的后续列表页、搜索、版块列表，以及存在时的一个版块帖子列表。默认两路并发、一百轮，整体预算六十秒，单次请求超时五秒。预热不调用发帖、评论、登录、标签创建，也不访问会增加浏览量的帖子详情；缓存填充和监控计数属于预期副作用。
4. 所有预热请求成功后，启动运行器结束。框架随后发布接流量状态，就绪探针在数据库可用时返回 `200`。反向代理或发布流程只在此时将新实例加入流量。
5. 预热失败或超过预算会使启动失败并关闭实例，不会记录错误后继续接入流量。应用停止时进入拒绝流量状态，配合优雅关闭等待已进入的请求结束。

预热请求使用仅保存在进程内的随机凭据，只允许回环连接上的指定读取路径，并继续经过正常安全过滤链。该凭据不会打印、不会向外部返回，预热结束后立即失效。伪造同名请求头、外部地址、写入请求和帖子详情都不能绕过启动门控。

## 配置

| 环境变量 | 默认值 | 说明 |
|---|---|---|
| `STARTUP_WARMUP_ENABLED` | `true` | 控制预热与业务门控。关闭意味着主动放弃这层启动保护，不能作为就绪问题的修复 |
| `STARTUP_WARMUP_ROUNDS` | `100` | 每轮遍历读取路径，一至一千轮 |
| `STARTUP_WARMUP_CONCURRENCY` | `2` | 一至四路并发，避免启动期间直接冲满连接池 |
| `STARTUP_WARMUP_TIMEOUT` | `60s` | 整体预算，不超过两分钟 |
| `STARTUP_WARMUP_REQUEST_TIMEOUT` | `5s` | 单次请求超时，不能超过整体预算 |

预热通过主业务端口的 `127.0.0.1` 地址访问自身；绑定地址应允许本机回环访问。支持随机端口和应用上下文路径，不依赖固定的 `8089`。

存活探针使用 `/actuator/health/liveness`；就绪探针使用 `/actuator/health/readiness`，包含框架就绪状态与数据库检查。缓存故障沿用既有可读降级策略，因此不强制把缓存纳入就绪检查。存活检查不依赖数据库，以免数据库故障触发无效的实例重启。

## 发布时等待就绪

启动实例后，执行以下只读探测：

```powershell
& .\scripts\wait-ready.ps1 -BaseUrl 'http://127.0.0.1:8089' -TimeoutSeconds 120
if ($LASTEXITCODE -ne 0) { throw '新实例未就绪，停止切换流量' }
```

脚本要求连续三次返回就绪后才成功退出。若有应用上下文路径，将其包含在 `BaseUrl` 中。使用容器编排或反向代理时，将同一个就绪地址配置为实例加入流量的检查地址；存活与就绪探针分别配置。此仓库没有预设某种代理或编排系统，脚本本身不会启动实例、切换代理或修改数据库。

退出旧实例前先从上游移除流量，等待连接排空，再发送正常终止信号。应用已设置优雅关闭，关闭阶段预算三十秒。强制结束进程不能替代正常终止和排空。

预热不能证明任意突发流量都可承受，也不能替代标签等写入路径的并发正确性修复。写入路径不通过造数来预热，因此首次写入仍可能存在初始化成本。新实例通过就绪检查后，应在上游逐步增加流量权重，观察错误率、连接等待与延迟后再继续增加，避免一次性把全部请求切到新实例。验证场景使用每秒二十次起步，前三十秒升至六十次，再用三十秒升至一百二十次，最后保持两分钟。具体比例与时间需结合部署实例数和实际容量调整。

## 数据与验证边界

这次标签创建使用数据库原子插入，并在调用者原事务中完成；不会预先创建业务标签、提交独立事务或修改已有标签标识。涉及多个标签时按名称顺序获取锁，帖子中的标签显示顺序仍按关联创建顺序返回。无需新增数据库结构迁移。

自动化测试覆盖同名标签并发、反向标签顺序、计数、失败回滚、启动门控、探针、凭据边界、预热失败，以及预热前后的业务数据一致性。运行包和真实数据库验证记录保存在本次独立输出目录；原有业务数据库和上一轮压测库不用于造数或清理。

框架就绪生命周期与探针行为参考 [Spring Boot 3.2.5 官方说明](https://docs.spring.io/spring-boot/docs/3.2.5/reference/html/actuator.html#actuator.endpoints.kubernetes-probes)。数据库原子插入参考 [PostgreSQL 官方说明](https://www.postgresql.org/docs/15/sql-insert.html) 和 [H2 兼容模式说明](https://h2database.github.io/html/features.html)。
